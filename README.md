# AA Pin the Needle — public pages

The web pages for the AA Pin the Needle game, published with GitHub Pages:

- [Privacy policy](https://birhanozcelik.github.io/aa-pin-the-needle/privacy.html): `privacy.html`
- [Home](https://birhanozcelik.github.io/aa-pin-the-needle/): `index.html`

The game links to the privacy policy from its title screen (Android and iOS)
and Android's ad-consent question, and Google Play, the App Store and AdMob
list the same address, so keep the file
name `privacy.html` when editing. Update "Last updated" when the policy
changes.
